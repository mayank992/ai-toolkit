# CLI reference

Generated by `make docs` from the argparse definitions. Do not edit by hand.

## `ait`

```
usage: ait [-h] [--version] COMMAND ...

ait: the ai-toolkit command line.

ait hindsight ...    self-improving memory (alias: hs)
ait rules ...        every rule Claude follows in a project, and the post-merge retro
ait setup ...        inventory your Claude Code setup and replicate it on another machine
ait ui               open the live, read-only dashboard
ait doctor           check that everything is installed and healthy
ait snapshot NAME    print a feature's dashboard JSON (for debugging the dashboard)
ait migrate-legacy   remove what a 0.1 install.sh left behind, once the plugin is enabled

positional arguments:
  COMMAND
    hindsight       self-improving memory: learn lessons from pushback
    rules           see and check every rule Claude follows in a project
    setup           inventory your Claude Code setup and replicate it on another machine
    ui              open the live, read-only dashboard
    doctor          check installation and hindsight health
    snapshot        print a feature's dashboard JSON
    migrate-legacy  remove what a 0.1 install.sh left behind (hooks in settings.json, links)

options:
  -h, --help        show this help message and exit
  --version         show program's version number and exit
```

## `ait hindsight`

```
usage: ait hindsight [-h] COMMAND ...

hindsight: learn from pushback (alias: hs)

positional arguments:
  COMMAND
    status    config, stores, queue summary
    queue     show captured correction moments
    capture   explicitly capture a lesson (used by /lesson)
    distill   turn queued moments into lessons (runs at SessionEnd)
    curate    merge / promote / retire / cap
    list      list lessons
    show      show one lesson with stats
    edit      open lessons in $EDITOR (edited lessons get pinned)
    rm        permanently delete a lesson
    promote   set lesson status to active
    retire    set lesson status to retired
    dismiss   set lesson status to dismissed
    restore   set lesson status to candidate
    review    triage candidates and auto-promoted lessons
    inject    preview what SessionStart would inject here
    report    pushbacks per session over time + lesson efficacy
    store     manage memory stores
    sync      redaction scan, commit, pull --rebase, push
    doctor    check installation health
    backfill  re-derive queued moments from their transcripts with current capture rules
    purge     delete data

options:
  -h, --help  show this help message and exit
```

## `ait rules`

```
usage: ait rules [-h] COMMAND ...

`ait rules ...`: every rule that shapes Claude Code in a project, and the post-merge retro.

ait rules show [PROJECT] [--json]              the rule stack: instructions, memory, hooks, lessons, problems
ait rules projects                             projects with any rules, most recent first
ait rules retro collect MR [--project DIR]     gather MR evidence for /mr-retro; prints the JSON path
ait rules retro log MR --proposed N --applied N [--note TEXT] [--project DIR]
ait rules fire HOOK DECISION [--project DIR]   append to the hook-fire log (for your own hook scripts)

positional arguments:
  COMMAND
    show      the rule stack of a project and its problems
    projects  projects with any rules, most recent first
    retro     post-merge retro steps used by /mr-retro
    fire      append one decision to the hook-fire log (call it from your hooks)

options:
  -h, --help  show this help message and exit
```
